# Sweet Delights - Artisan Bakery & Pastry Shop

A delightful, warm, and responsive website crafted for an artisan bakery and pastry shop, built with **HTML5** and **CSS3**.

## ✨ Key Features
- **Gourmet Bakery Catalog**: Showcases custom wedding cakes, birthday pastries, artisan breads, cupcakes, and seasonal sweets.
- **Multi-Course Bakery Showcase**: Structured multi-page journey detailing ingredients, baker credentials, and flavor options (`firstpage.html` through `sixthpage.html`).
- **Visual Delight Gallery**: High-resolution photography of pastry creations and bakery crafts (`gallery.html`, `gallery.css`).
- **Custom Cake Inquiries**: Order form for bespoke celebration cakes and catering services.
- **Mobile-Optimized Design**: Beautiful typography, warm pastel color palettes, and responsive viewing.

## 📁 Project Structure
- `firstpage.html` - Homepage and bakery introduction
- `secondpage.html` - Signature cakes and menu selections
- `thirdpage.html` - Custom cake design options
- `fourthpage.html` / `fivethpage.html` / `sixthpage.html` - Specialty pastries, customer reviews, and story
- `gallery.html` - Comprehensive visual gallery
- `images and video/` - High-quality bakery media assets

## 🚀 Getting Started
Clone the repository and open `firstpage.html` in any browser:
```bash
git clone https://github.com/abdullah3111/sweet-delights-bakery-portal.git
cd sweet-delights-bakery-portal
# Open firstpage.html in your browser
```
